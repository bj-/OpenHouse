Вести обмерную 3D-модель дома и участка Vesta в миллиметрах для работ по дому. Рабочая [сборка AutoCAD](../generated/Vesta.dwg) содержит [план моделирования](../generated/PLAN.md) и [виды для ремонта](../generated/WORK.md). Исходная сборка - Vesta Project.dwg.
