# 0001. Источники ремонтной сборки Vesta

**Принято 2026-11-24.**

Рабочая сборка опирается на существующий обмерный каркас. Для него сохраняем трехмерные тела и их координаты, а поиск стоек и перемычек упрощаем слоями по стенам и по форме элементов.

Видимые кабели привязываем по фото и панорамам до зашивки. Для каждого отрезка сохраняем кадр и плоскость привязки. Схемные трассы и варианты раскладки из исходных DWG доступны отдельными слоями. Толщины и глубины, требующие контрольного обмера, записываем в памятке.

Так можно включить нужные материалы и сети для осмотра стены или пола, сравнить их с обмером на месте и заменить приблизительные привязки проверенными.
